# wars333 — визуальный клиент для Minecraft 1.21.11 (Fabric)

## Сборка
1. Нужны JDK 21 и Gradle 9.x.
2. Gradle wrapper не включён: возьми его из шаблона на https://fabricmc.net/develop/ (или выполни `gradle wrapper`).
3. Проверь в `gradle.properties` актуальные `yarn_mappings`, `loader_version`, `loom_version`, `fabric_version` для 1.21.11.
4. `./gradlew build` → готовый мод в `build/libs/wars333-1.0.0.jar` → в папку `mods` вместе с Fabric API.

## Управление
| Кнопка | Действие |
|---|---|
| **Right Shift** | меню модулей (ЛКМ вкл/выкл, ПКМ настройки, СКМ назначить кнопку, DEL — сбросить) |
| **X** | AutoSwap: тотем в левой руке ⇄ сфера (меняется в меню) |
| **C** | AutoAction: слот с эндер-жемчугом → бросок → возврат слота |

Настройки сохраняются в `config/wars333.json`, аккаунты — в `config/wars333_accounts.json`.

## Что внутри
- **HUD** — ватермарк (FPS, пинг, ник), список модулей с анимацией, координаты и BPS, эффекты. 5 цветовых схем.
- **Ambience** — темы неба: Галактика, Аврора, Туманность, Закат, Кровавая луна, Океан и автоматический «Цикл». Звёзды и Млечный Путь, полярное сияние, тонировка.
- **Particles** — падающие снег, лепестки, звёзды, искры, пепел.
- **Главное меню** — космический фон, планета, падающие звёзды, пиксельный логотип.
- **Аккаунты** — список офлайн-ников, добавление, случайный ник.
- **Optimizer** — снижает настройки графики и количество эффектов клиента, при выключении всё возвращает.
- **AutoSwap / AutoAction** — свап предметов и бросок жемчуга по кнопке.

## Если сборка не проходит
Код писался без возможности скомпилировать его с Minecraft, поэтому возможны расхождения имён в маппингах. Самые вероятные места:
- `AccountManager.login` — конструктор `Session` (число аргументов);
- `ParticlesMod` — `world.addParticleClient` (раньше `addParticle`);
- `OptimizerMod` — `GraphicsMode` / `CloudRenderMode`;
- `ClientWorldMixin` — подмена цвета неба (если сигнатура другая, миксин просто не применится).
